# このごろ アイコンアセット

採用案「雲と丘」。雲、丘、その後ろから昇る太陽で、ひらがなの「こ」を表す。雲が1画目、丘が2画目。
`symbol.svg`を形状の唯一の正本とする。生成済みファイルは直接編集しない。

## カラー

- ライト: 背景 `#FFFFFF`、絵柄 `#000000`
- ダーク: 背景 `#000000`、絵柄 `#FFFFFF`

絵柄は白黒1色のベタ塗り。太陽と丘のあいだは、丘を太らせたマスクで透明に抜く（背景色の線で塗らない）ため、透過版でも下地が見える。
書き出しスクリプトは`class="ink"`の塗りを明暗に合わせて差し替える。ブラウザ用icon.svgと起動画面（`index.html`）は、端末やアプリの明暗設定に合わせて絵柄の色も切り替える。

## 書き出し

```sh
npm run icons:export
```

SVG正本から背景付き・透過のSVG、16〜1024pxのPNG、favicon.icoを生成する。
ホーム画面用は四隅まで背景を塗り、OS側に角丸処理を任せる。
maskable版は絵柄を80%に縮小して中央のセーフエリアに収める。
ブラウザ用icon.svgは端末の明暗設定で背景を切り替える。

PWAのmanifestとApple touch iconには互換性のあるライトPNGを指定する。
インストール済みホーム画面アイコンの更新時期やダーク版の自動選択はOSに依存するため、黒背景PNGも個別に書き出す。
ログイン・起動・設定では既存のアプリ内テーマ切替を通じて透過版を表示する。
