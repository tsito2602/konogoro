# Product Overview

## コンセプト

**夫婦から始まる、家族限定の写真・動画タイムライン。**

夫婦が旅行、日帰りのお出かけ、外食、記念日、日常などで撮影した写真・動画を、招待した家族だけに簡単に共有するためのプライベートWebアプリ。

子ども向け家族写真共有アプリの体験は参考にするが、子どもの登録やプロフィールを前提としない。

主な利用期間は子どもが生まれるまでを想定しているが、設計上は期間制限を持たせない。

## 目的

- 写真・動画を家族だけに簡単に共有する
- LINEを入口として、家族側の利用ハードルを下げる
- 旅行中でもスマホからまとめて投稿できる
- SNS的な「評価」「承認」「競争」を持ち込まない
- 基本無料で維持し、写真・動画が数十GBになって月100円程度なら許容する

## プロダクト思想

- 写真・動画が主役
- UIは静かで控えめ
- 家族だけの閉じた空間
- 「いいね」は不要
- コメントは会話のため
- 「見たよ」は受信確認のための自動既読
- イベントは整理用
- タイムラインが日常の入口
