## 維持する判断

- 写真・動画が主役。家族限定。いいね、リアクション、ランキング、AI選別等を追加しない。
- viewerは閲覧・コメント。投稿・管理の導線とAPI権限を守る。
- タイムラインという名称と5タブ、PC左ナビの追加枠、D&D、イベント引継ぎを維持する。
- 画面ヘッダーに定型サブタイトルを追加しない。閲覧者向け案内に投稿説明を追加しない。
- ガイドの全画面・常時閉じる・スワイプ・真円インジケーターと、ライトの実アプリアイコンによるLINE説明を維持する。
- 利用者向けの導入文で「夫婦」を強制しない。ホーム画面追加の自動案内を復活させない。
- 閲覧は自動の受信確認、コメントは投稿単位。写真をすべて見せるために強制操作を増やさない。
- 共有ボタン、画像付きLINE通知、権限変更を今回の見た目改善へ混ぜない。

## 2026-09-07：思い出に触れる道具への改訂（#111）

ユーザー提供の2本のUI動画（機能固有の変形を持つスイッチ、質感のあるウィジェット）と全画面の提案を根拠に改訂。「見やすさを優先しすぎてデザインが犠牲になっている」という指摘を受け、美しさと操作の楽しさも品質目標にする。参照したmainの文書と画面構成に基づく設計であり、全画面の実機監査結果ではない。

| 以前の方針・課題                 | 改訂                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------- |
| 分かりやすさ・抑制が判断の中心   | 構図、触りたくなる質感、機能固有の表情、操作の連続性も合格基準へ                |
| 通常カードの影を禁止             | 写真・表紙の重なり、部品の厚み、持ち上げの高さを表す陰影を設計                  |
| ナビの背景表現を一律禁止         | 小さな印・局所的な面・アイコンの変化で選択状態を表現                            |
| 動きを短い押下反応へ集約         | 開く・戻る・選ぶ・並べる・届けるの意味で設計し強弱を付ける                      |
| 見やすさに寄与しない演出をゼロへ | 魅力、写真の見え方、性能を比較して範囲・強度を調整                              |
| 通常ヘッダー基準の全画面適用     | 表紙・年月・ログインでは文字の大小を構図として設計。共通ヘッダーの1行省略は維持 |
| 画面別の魅力が曖昧               | UI・UX仕様に入口から空・失敗状態まで目標表現を一覧化                            |

### 維持する成立条件

権限、写真の色と構図、読み上げ・キーボード操作、文字拡大、動きを減らす設定、入力の保持、実際の処理に基づく成功表示、動画の手動移動、投稿単位の既読を維持する。数値基準だけでデザイン完成とは扱わない。リアクションは候補に留め、機能追加を本改訂へ混ぜない。

### 適用順と完了範囲

本PRは4文書の改訂のみ。アプリのバージョン、コード、画面、ステージング、本番は変更しない。マージ後の個別実装は改訂済みmainから開始し、まずイベント開閉・写真並び替え・LINE通知切替の試作で世界観を確認する。その結果から共通部品と各画面へ展開する。試作・画面実装の完了は各Issueで別途記録し、文書のマージをUI反映済みと報告しない。
