# 閲覧ナビゲーションのタスク確認

関連Issue: #49。改訂基準: #53、04_UI_UX_SPEC.md、11_DESIGN_REVISION.md。

状態: 手順準備済み・利用者による確認は未実施。AIの操作確認は参加者の結果に数えない。本書の追加だけで #49 を完了・クローズしない。

## 目的

タイムライン・お知らせ・イベント・アルバムの使い分けを、説明を聞かずに判断できるか確認する。5タブと現在の名称を保って実施し、つまずいた場所を根拠に変更要否を決める。

## 準備

- 対象は実際の利用に近いviewer 5人以上を目標とする。参加は任意。氏名や連絡先は記録せず、参加者A〜Eとする。
- ステージングの同一バージョンを使う。viewer表示にして、個人写真を含まないサンプルを用意する。
- 未閲覧投稿2件、サンプル旅行イベント、前月の写真、コメントのお知らせを用意する。各参加者の未閲覧状態は確認前に整える。共通アカウントの既読を使い回す場合は、データ状態が変わるため実施者が都度確認する。
- 端末、文字サイズ、開始画面、バージョン、ガイドを見たかを記録する。普段の文字サイズ設定を変更させない。
- 順序の学習効果を減らすため、A/C/Eは1→2→3→4、B/Dは3→4→1→2で実施する。
- 1人10分程度を目安とし、制限時間で急がせない。2分迷い続けた場合は打ち切り、援助が必要だったと記録する。

## 読み上げる依頼と成功条件

操作名やタブ名を先に教えない。成功する経路を一つに限定しない。

| タスク       | 参加者への依頼                           | 成功条件                                       | 観察する迷い                                             |
| ------------ | ---------------------------------------- | ---------------------------------------------- | -------------------------------------------------------- |
| 1 新しい写真 | 最近追加された写真を見てください         | 未閲覧投稿へ到達し、次の投稿へ進める           | お知らせを写真一覧だと解釈するか、未閲覧の入口に気付くか |
| 2 旅行単位   | サンプル旅行の写真をまとめて見てください | 該当イベントとその投稿を開く                   | イベントとアルバムの違い、写真を開いた後の戻り先         |
| 3 年月単位   | 先月に撮った写真を探してください         | 対象年月を選んで写真を開く                     | 月タブ・年全体表示、投稿の日付と撮影年月の混同           |
| 4 コメント   | 写真に届いたコメントを見てください       | コメントのお知らせから対象投稿の会話へ到達する | お知らせの意味、コメントと写真の入口の混同               |

各タスクの後、「最初にそこを押したのはなぜですか」「次に何が出ると思いましたか」を短く聞く。誘導して正解させた場合は自力成功に数えない。

## 判断方法

1. 同じ箇所・同じ理由で2人以上が迷った場合、その問題を改善候補にする。
2. 名称だけで解決するか、表示・遷移の問題か、項目数の問題かを区別する。
3. タスクを完了できた経路が想定と違うだけなら、誤操作と断定しない。
4. 必要な最小変更を別の実装Issueへ切り出し、観察した事実と予想される改善を分ける。
5. 変更不要ならその理由を記録する。データ増加や同じ迷いの再発を再検討のきっかけにする。

完了時に #49 へ参加人数、版、タスク別の結果、変更要否と理由を記録する。未実施・不足人数・途中中止はそのまま示す。利用者への連絡や募集を自動で送信しない。
