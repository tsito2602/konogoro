# このごろ — デザインの考え方

このごろは、家族の近況を写真と短い言葉で見返す場所。目指すのは「思い出に触れる道具」。写真日記の親しみ、フォトブックの質感、触れると応えてくれる小さな楽しさを全画面に持たせる。

## 判断の軸

1. 美しさ、触りたくなる質感、機能に意味のある動きを、使いやすさと並ぶ品質目標にする。親世代が使うことを、表現を一律に簡素化する理由にしない。
2. 写真の内容を主役に、文字の大小、余白、面の重なり、陰影で構図を作る。全要素の同形・同密度への統一を目標にしない。
3. 開く、選ぶ、並べる、届けるという操作の意味を、動きと形で表す。押下の縮小だけで完成と判断しない。
4. 選んだ写真や表紙から詳細へつながり、閉じると見ていた場所へ戻る。操作の前後に連続性を持たせる。
5. 読める文字、見つかる操作、権限、正確な状態表示を成立条件として守り、その中で表現を磨く。問題が出たら配置・局所背景・動きの範囲を調整し、一律に影や動きを撤去しない。
6. 静止画の構図と、操作中の気持ちよさを両方レビューする。数値基準の達成だけでデザイン完了としない。

## このごろらしい世界観

温かい白、写真の重なり、柔らかな陰影、少し厚みのある操作部品を基本にする。黄色は主操作、新着のしおり、選択状態に効かせる。写真そのものの色は変えない。紙らしさは面・縁・影で表し、読みにくい紙目や過度な古びた装飾を必須にしない。

| 画面               | 視覚と体験の中心                                   |
| ------------------ | -------------------------------------------------- |
| ログイン・使い方   | 世界観を伝える入口と、実際の操作が分かる小さな実演 |
| タイムライン・新着 | 写真日記と、新しく届いた思い出のしおり             |
| イベント           | 表紙を選び、開き、元へ戻せるフォトブック           |
| アルバム           | 年月をたどり、一枚の写真へ近づく写真カレンダー     |
| ビューワ           | 写真の構図を保ち、指に追従する鑑賞道具             |
| 投稿詳細・お知らせ | 写真のそばに家族の言葉や気配が加わる場所           |
| 投稿・編集         | 写真を机に広げ、並べて届ける作業場                 |
| 設定               | 通知や表示の状態に表情のある、小さな道具の集まり   |
| 招待・家族管理     | 招待状を届け、承認された家族が加わる場所           |

評価・競争を促す数字や定型サブタイトルは追加しない。案内・空状態には世界観に合う小さな図を使える。装飾のためだけに新機能を増やさず、リアクションなどの候補は別途判断する。
